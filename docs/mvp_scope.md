# AC-001 - Phạm vi MVP

## 5 tính năng trong phạm vi

| Tính năng | Mục đích |
|---|---|
| User Authentication | Người dùng đăng ký và đăng nhập |
| Artwork Upload | Tải ảnh lên hệ thống |
| Personal Gallery | Quản lý các ảnh của riêng người dùng |
| Infinite Canvas | Kéo thả ảnh lên canvas để ghi chú và sắp xếp |
| AI Image Check | AI phân tích hoặc kiểm tra ảnh |

## Ngoài phạm vi MVP

### Social

- Like
- Comment
- Follow
- News Feed

### Collaboration

- Realtime multi-user editing
- Share canvas
- Invite collaborators

### Advanced Canvas

- Layer locking
- Smart snapping
- Vector drawing
- Shape library
- History version
- Multiplayer

### Advanced AI

- Image generation
- Style transfer
- Chatbot
- Auto tagging

### Media, Gallery và 3D

- Video, GIF và audio
- 3D model
- 3D gallery
- Three.js scene
